ATIVIDADE DE JAVASCRIPT

Aprendendo programação ✨

Veja os comandos WHILE, SWITCH, DO-WHILE e FOR funcionando diretamente nesta página.

1. WHILE — Contagem de produtos

O WHILE repete uma instrução enquanto a condição for verdadeira.

2. SWITCH — Tipos de pele

Escolha um tipo de pele para receber uma sugestão de cuidado.

3. DO-WHILE — Rotina de skincare

O DO-WHILE executa o bloco pelo menos uma vez antes de verificar a condição.

4. FOR — Etapas de cuidados

O FOR percorre as etapas da rotina de skincare.
